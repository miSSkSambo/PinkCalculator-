# 3D Pink Calculator with History

A single-file, animated 3D pink calculator (HTML/CSS/JS) with expression history.
Ready for GitHub Pages.

## Deploy to GitHub Pages
```bash
git init
git add .
git commit -m "Initial commit: 3D Pink Calculator"
git branch -M main
git remote add origin https://github.com/YOUR_USER/pink-calculator-3d.git
git push -u origin main
```
